# 📊 Student Performance Analytics

## Description
Student Performance Analytics is a Python project that analyzes student marks and generates academic performance reports. It calculates grades, percentages, class averages, subject statistics, and identifies students who may need additional academic support.

## Features
- Display individual student results
- Calculate totals, percentages, grades, and pass/fail status
- Calculate the overall class average
- Identify the highest-scoring student
- Analyze subject-wise averages, highest marks, and lowest marks
- Find students needing improvement
- Search students by roll number

## Technologies Used
- Python 3
- Lists and dictionaries
- Functions and conditional statements
- Loops and built-in statistical calculations

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python main.py`.

## Dataset
The project currently uses sample student records defined in `main.py`. Replace them with authorized, anonymized data when adapting the project for real use.
